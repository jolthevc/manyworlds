# Sand.ai video models (research, 2026-11-20; no spend)

Question: is Sand.ai cheaper or better than InfiniteTalk for lip-synced talking video, or than Wan 2.2 for
story clips? Sources linked; unverified items marked.

| Model | What | Licence | Weights | Notes |
|---|---|---|---|---|
| **Gaga-avatar** `avatar-h1` / `-pro` | photo + **your own audio** (+ optional text) → talking video | API terms not found | API only (platform.gaga.art) | the only Sand.ai option that lip-syncs to a supplied voice; 20 req/min, audio < 60 s, 16:9 / 9:16 / 1:1; no public price (credits; business@sand.ai) |
| **GAGA-1** / Pro | text dialogue → talking video (own voice) | API terms not found | API only | 16:9 (Pro adds 9:16, voice reference) |
| **daVinci-MagiHuman** (15B, with SII-GAIR) | text + reference image → video **and** speech | Apache-2.0 (depends on stable-audio-open: Stability Community Licence, check) | open | 256p base, up to 1080p; 8-step distill; 5 s at 540p in 8 s on one H100; lip-sync to *supplied* audio unconfirmed; WaveSpeed hosts it at ~$0.04/s (720p) |
| **MAGI-1** (4.5B / 24B) | image/text/video → video, no audio | Apache-2.0 | open | 4.5B fits one 4090; Physics-IQ I2V 30.2 vs Wan 2.1 20.9 (vendor numbers); no speed figures |
| **MAGI-2-preview** (114B MoE) | video + sound | Apache-2.0 | open | 8 Hopper GPUs; impractical |

Sources: github.com/SandAI-org/daVinci-MagiHuman, huggingface.co/GAIR/daVinci-MagiHuman,
platform.gaga.art/docs, gaga.art/blog/gaga-1, github.com/SandAI-org/MAGI-1, huggingface.co/sand-ai/MAGI-1,
github.com/SandAI-org/MAGI-2-preview, wavespeed.ai (MagiHuman pricing).

**Recommendation.** Talking video: ask Sand.ai for Gaga-avatar pricing and commercial terms, then compare a
few clips against InfiniteTalk with the 8-step distill LoRA (estimated ~$0.08-0.10 per attempt on an A40 if a
render takes 8-10 min; unmeasured). Try MagiHuman on WaveSpeed with our audio (~$0.24 per 6 s attempt) only if
it is confirmed to follow supplied audio. Story clips: low priority; MAGI-1 4.5B is a possible A/B against Wan
2.2 only if Wan's acceptance rate is poor.
